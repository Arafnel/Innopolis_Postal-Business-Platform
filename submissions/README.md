# Сданные работы

Здесь у каждого студента своя папка `<логин-GitHub>/` с подпапками `lr1/` (если ЛР-1 сдана сюда), `lr2/`, `lr3/`, `lr4/`.

Работы попадают сюда только через запрос на слияние из форка и только после приёмки преподавателем. Порядок сдачи — в [README репозитория](../README.md#как-сдавать-работу-в-этот-репозиторий).

Изменять можно только свою папку.
